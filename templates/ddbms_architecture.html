Section 4 · query execution

Distributed Query Processing (DQP)

Queries are localized before parallel execution so irrelevant partitions never receive the request.

01

Decompose & Localize

Parse the global relation and map Journeys to each Journeys_Local fragment.

02

Push Predicates

Apply filters at the edge so only qualifying rows cross the network boundary.

03

Scatter in Parallel

Dispatch localized subqueries concurrently to active regional WAL nodes.

04

Gather & Merge

Union the results at the coordinator and return a transparent execution plan.
